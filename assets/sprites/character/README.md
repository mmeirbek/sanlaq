# Персонаж: листы по слоям

Листы генерирует `tools/artgen/characters.py`. Руками их не правят, пересобирают:

```bash
python tools/artgen/build.py
```

## Формат листа

Это контракт `scripts/entities/character_visual.gd`, менять его нельзя.

- **4 строки** — направления: вниз, вверх, влево, вправо. Вправо — зеркало влево.
- **6 колонок** — кадры: покой ×2 (второй — вдох), шаг ×4.
- Клетка — 32×32 пикселя арта. Лист сохраняется ×2: кадр 64×64, лист 384×256.
- Подпрыгивание при ходьбе добавляет код, шагом в один пиксель арта. В кадрах его нет.

## Слои

Слои накладываются снизу вверх.

| Слой | Папка | Что рисует |
|---|---|---|
| Тело | `base/` | кожа, лицо, волосы; 3 варианта |
| Обувь | `shoes/` | кебіс, мәсі, саптама етік |
| Штаны | `pants/` | шалбар, әшекейлі шалбар |
| Торс | `torso/` | көйлек, камзол, шапан |
| Голова | `head/` | бөрік, тақия, тымақ, кимешек, сәукеле |

Все слои рисуются в одной геометрии фигуры и с одной позой на кадр, поэтому сходятся
пиксель в пиксель. Иконки тех же предметов лежат в `assets/sprites/items/`
(`tools/artgen/item_icons.py`).

## Новый предмет одежды

1. В `tools/artgen/characters.py` добавьте функцию рисования слоя и запись в `ITEMS`.
2. В `tools/artgen/item_icons.py` добавьте иконку и запись в `ICONS`.
3. Запустите `python tools/artgen/build.py`.
4. Создайте `data/clothing/<id>.tres` по образцу любого другого предмета:
   `texture_path` указывает на лист слоя, `icon_path` — на иконку.
