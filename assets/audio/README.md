# ЗВУКИ И МУЗЫКА

Просто клади файлы с нужными именами в подпапки, и игра сама их подхватит.
Поддерживаются форматы: `.ogg`, `.mp3`, `.wav`.

Если файла нет — игра использует встроенный синтезатор (запасной вариант).

> **ВАЖНО**: имя расширения должно совпадать с реальным форматом файла.
> Если положишь MP3-файл с расширением `.ogg` — Godot не сможет его
> переимпортировать и звук не будет играть. Проверь командой:
> `file assets/audio/sfx/catch.ogg` → должен сказать `Ogg data`.

---

## 1. ФОНОВАЯ МУЗЫКА → папка `music/`

Положи сюда **любой** аудиофайл (''Молданазар'', акустика и т.д.):
Будет играть по кругу на всех экранах.

```
assets/audio/music/мой_трек.ogg
```

Громкость и вкл/выкл — в «БАПТАУЛАР».
(Тоже работает старый путь: `assets/audio/menu_music.ogg` — если файл один.)

---

## 2. ЗВУКОВЫЕ ЭФФЕКТЫ → папка `sfx/`

Имя файла = какой эффект он заменяет. Пример:

```
assets/audio/sfx/catch.ogg      <- ловля / поимка
```

### Все доступные имена эффектов:

| Имя файла         | Когда играет                                |
|-------------------|---------------------------------------------|
| `step.mp3`        | шаги игрока                                 |
| `step_sprint.mp3` | шаги на спринте                             |
| `sprint.mp3`      | рывок (SHIFT)                               |
| `catch.mp3`       | кого-то поймали                             |
| `quiz_correct.mp3`| правильный ответ в викторине                |
| `quiz_wrong.mp3`  | неправильный ответ                          |
| `echo.mp3`        | способность «Үн тыңдау» (звуковой импульс)  |
| `fog.mp3`         | туман накрыл карту                          |
| `yurt.mp3`        | вход в юрту                                 |
| `splash.mp3`      | вход в воду                                 |
| `defeat.mp3`      | поражение / игрок пойман                    |
| `victory.mp3`     | победа в матче                              |

Любой из них можно пропустить — если файла нет, останется синтезаторный звук.
