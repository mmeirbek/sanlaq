# ОЗВУЧКА ЭКРАНОВ-ОБЪЯСНЕНИЙ

Здесь лежит голосовое сопровождение брифингов — экранов «как играется и чему
учит», которые показываются перед каждым режимом.

```
voice/
├── kk/    <- казахская озвучка
└── en/    <- английская
```

Игра сама выбирает папку по текущему языку и берёт файл с нужным именем.
Поддерживаются `.ogg`, `.mp3`, `.wav`.

---

## Как называются файлы

`<id режима>_<номер строки>.wav`

Номер сквозной: сначала идут строки «как играется» (`how_to_play`), затем
«чему учит» (`skills`) — в том же порядке, в каком они записаны в
`data/briefings/<режим>.tres`.

```
kk/togyz_qumalaq_01.wav   <- первый шаг «как играется»
kk/togyz_qumalaq_05.wav   <- первый пункт «чему учит»
```

Посмотреть полный список нужных файлов с текстами:

```
python3 tools/generate_voice_lines.py --list
```

---

## Как обновить озвучку

Файлы уже сгенерированы системным синтезатором macOS: казахский — голосом
**Aru**, английский — **Samantha**.

**Изменил текст в `.tres`?** Удали соответствующий `.wav` и прогони:

```
python3 tools/generate_voice_lines.py          # сгенерирует только недостающее
python3 tools/generate_voice_lines.py --force  # перезапишет всё
```

Не забудь добавить новую строку и её английский перевод в
`assets/i18n/ui_strings.csv` — иначе скрипт скажет «НЕТ ПЕРЕВОДА», а на экране
вместо английского покажется казахский.

**Хочешь живой голос вместо синтезатора?** Просто положи свои файлы с теми же
именами — скрипт без `--force` их не тронет, а игра всегда предпочитает файл
любому синтезатору.

---

## Если файла нет

Ничего не сломается. Порядок такой:

1. есть файл → играет он;
2. файла нет → строку читает системный синтезатор речи
   (нужен голос этого языка в системе; в браузере казахского голоса обычно нет);
3. нет и голоса → тишина, но экран всё равно подсвечивает строки по очереди
   в темпе чтения.

Поэтому для веб-сборки записанные файлы — единственный надёжный вариант,
особенно для казахского.

---

## Размер

Исходники — WAV 22050 Гц моно, около 9 МБ на оба языка. В собранную игру они
попадают уже сжатыми (Godot жмёт их в QOA при импорте) — примерно 1.8 МБ.
Тишина в начале и в конце обрезается настройкой `[importer_defaults]` в
`project.godot`, чтобы строки читались подряд без провалов.
