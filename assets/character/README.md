# Ассеты персонажа (слои и замена)

## Формат листа
Каждый лист — **один PNG**: 4 строки × 6 колонок кадров по 64×64.

```
Строки: down, up, left, right   (направления, право = зеркало левого)
Колонки: idle0, idle1, walk0, walk1, walk2, walk3
Размер листа: 384×256
```

## Слои
| Слой | Файл | Что рисует |
|------|------|-----------|
| Тело | `base/base.png` | кожа, волосы, лицо |
| Голова | `head/<id>.png` | головной убор (бөрік, тақия...) |
| Торс | `torso/<id>.png` | камзол, көйлек, шапан |
| Штаны | `pants/<id>.png` | шалбар |
| Обувь | `shoes/<id>.png` | кебіс, мәсі, етік |

## Как заменить/перерисовать
1. Возьми `TEMPLATE.png` (сетка 4×6, силуэт тела).
2. Нарисуй свой лист поверх (тот же размер 384×256, тот же формат).
3. Сохрани с тем же именем в ту же папку.
4. Всё: персонаж и превью подхватятся автоматически.

## Превью (квиз/шкаф)
`assets/items/<id>.png` — картинка 128×128 предмета отдельно. Тоже перерисовывается свободно.

## Перегенерация с нуля
```
python3 tools/generate_character.py
```
