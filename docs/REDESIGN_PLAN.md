## Единый стиль: правила

Эти правила обязательны для каждого PR. Пункты 1–4 проверяет скрипт в CI.

1. **Ничего не пиксельного.** Нельзя использовать:
   - фото;
   - векторные и мультяшные картинки;
   - гладкие шрифты;
   - градиенты;
   - скруглённые углы;
   - размытие;
   - мягкие тени.
2. **Мир — на одной сетке.**
   - Один пиксель арта равен 2 пикселям экрана при базовом разрешении 1280×720.
   - Масштаб всегда целый: ×1, ×2, ×3. Дробный масштаб и ресайз спрайтов запрещены.
   - Персонаж — 48×80, 8 направлений, как в atilla. Иконки — 32×32.
3. **Общая палитра.** Спрайты мира, иконки и рамки интерфейса используют только цвета
   из `tools/artgen/palette.py`. Альфа-канал — только 0 или 255, без полупрозрачных краёв.
4. **Детальный пиксель только в меню.** Фоны и карточки героев приводятся к общей палитре
   (не больше 64 цветов). В игровой мир их не ставим.
5. **Единые приёмы рисования, как в генераторе atilla:**
   - свет сверху-слева;
   - тонированный тёмный контур;
   - цилиндрическая светотень;
   - холодные тени и тёплый ободок.
6. **Вид 3/4 и сортировка по Y.** Это касается всех объектов мира во всех режимах.
7. **Интерфейс.**
   - Золотая пиксельная рамка на бордовой, «чернильной» или пергаментной заливке.
   - Тени ступенчатые.
   - Минимальный размер текста при 1280×720: 20 px для основного текста, 16 px для подписей.
8. **Эффекты.** Только пиксельные: квадратные искры, ступенчатая виньетка, пиксельная пыль.
9. **Новый ассет попадает в игру только двумя путями:** через `tools/artgen` или как
   одобренный импорт, прошедший `style_check`.
10. **Смешения в `main` не бывает.** Каждый PR переводит экран целиком. Старый ассет
    удаляется, как только его перестали использовать.

## Правила работы

1. **Сначала страховка, потом изменения.** Каждая задача начинается с зелёных тестов и
   скриншотов «до» (`tools/capture.gd`).
2. **Визуал и механика — разными коммитами.**
3. **Ветки и PR.** Ветка называется `redesign/<этап>-<кратко>`. `main` автоматически
   деплоится на GitHub Pages.
4. **«Готово» означает:**
   - тесты зелёные;
   - `style_check` зелёный;
   - есть скриншоты «до/после»;
   - экраны проверены в форматах 16:9, 20:9 (телефон) и 4:3 (планшет);
   - нет новых предупреждений Godot.

## Этап 8. Новая игра «Тарих жолы» по концепции atilla

Порядок такой: **сначала глава I (Керей) полностью**, затем II и III.

**Как играется:**

1. Режим выбирается в «Ойын режимдері».

6. Задание или мини-игра.
7. Награда: XP и новые статьи энциклопедии.
8. Переезд на телеге по карте маршрута.
9. Финал. Его текст зависит от «бірлік».
