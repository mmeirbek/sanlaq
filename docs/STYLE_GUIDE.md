# Единый стиль САҢЛАҚ

Правила обязательны для каждого PR. Пункты 1–4 и контраст проверяет
`tools/style_test.gd` в CI. Как рисовать арт — [ART_PIPELINE.md](ART_PIPELINE.md),
как собирать интерфейс — [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).

1. **Только пиксель.** Нельзя: фото, векторные и мультяшные картинки, гладкие шрифты,
   градиенты, скруглённые углы, размытие, мягкие тени, полупрозрачные спрайты.
2. **Одна сетка.**
   - Пиксель арта — 2 пикселя экрана при 1280×720. Окно масштабирует экран с шагом
     0,5 (`PixelScale`), так что пиксель арта на экране всегда целый.
   - Картинки — только в целом масштабе. Дробный масштаб и ресайз спрайтов запрещены.
   - Персонаж — клетка 32×32, 4 направления. Иконки — 32×32.
3. **Общая палитра** `assets/palette/sanlaq.gpl`. Альфа — только 0 или 255.
4. **Детальный пиксель — только в меню.** Фоны и карточки сведены к палитре, в мир их не
   ставим.
5. **Приёмы рисования как в atilla:** свет сверху-слева, тонированный тёмный контур,
   цилиндрическая светотень, холодные тени и тёплый ободок.
6. **Вид 3/4 и сортировка по y** — для всех объектов мира.
7. **Интерфейс.**
   - Золотая пиксельная рамка на бордовой, «чернильной» или пергаментной заливке.
   - Тени ступенчатые.
   - Текст не мельче 20 px, подписи — не мельче 16 px (при 1280×720).
   - Контраст текста к фону — не ниже WCAG AA: 4,5 для обычного текста, 3 для крупного.
   - Вид узла задаёт `theme_type_variation`, а не `theme_override_*`.
8. **Эффекты — пиксельные.** Квадратные искры, ступенчатая виньетка, пиксельная пыль.
   Вместо полупрозрачности — мигание целыми кадрами или шахматка; вместо увеличения
   фигуры — вспышка `PixelBurst`.
9. **Новый ассет — только через `tools/artgen`** или как импорт, прошедший
   `style_test`.
10. **Без смешения стилей в `main`.** PR переводит экран целиком; старый ассет удаляется,
    как только его перестали использовать.
11. **Текст — через перевод.** Видимая строка идёт через `tr()`, ключ — казахский текст в
    `assets/i18n/ui_strings.csv` с английским переводом. Символы — только те, что есть в
    шрифтах (`font_coverage_test`); вместо ✓ и ✗ — иконки `check` и `cross`.
