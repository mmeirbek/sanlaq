# Арт-пайплайн

Весь пиксель-арт САҢЛАҚ рисуется кодом на Python или переносится из atilla со
сведением к палитре. Руками PNG не правят: правят генератор и пересобирают.

## Как пересобрать

```bash
python tools/artgen/build.py                                    # весь арт (нужен Pillow)
godot --headless --import --path .                              # импорт новых PNG
godot --headless --path . --script res://tools/build_theme.gd   # тема, если менялись рамки
tools/run_tests.sh                                              # style_test проверит арт
```

Генераторы детерминированы: повторная сборка даёт те же пиксели. Pillow другой версии
может записать PNG другими байтами при тех же пикселях — такие файлы не коммитьте.

## Генераторы (`tools/artgen/`)

| Модуль | Что рисует | Куда |
|---|---|---|
| `palette.py` | читает палитру и токены, `quantize()` сводит картинку к палитре | — |
| `pixel.py` | холст, маски, заливка со светом сверху-слева, контур, сохранение ×2 | — |
| `ui_frames.py` | рамки кнопок, панелей, карточек, переключателей, ✓ / ✗ | `assets/ui/frames/` |
| `hud_icons.py` | иконки HUD и сенсорного стика | `assets/ui/hud/` |
| `characters.py` | персонаж по слоям: 3 тела, 13 вещей, 4 направления × 6 кадров | `assets/sprites/character/` |
| `item_icons.py` | иконки 13 вещей 32×32 | `assets/sprites/items/` |
| `food_icons.py` | 8 блюд для «Абай айтады» | `assets/sprites/food/` |
| `mode_art.py` | картинки режимов и ролей для меню и лобби | `assets/sprites/modes/` |
| `world_art.py` | мир Соқыртеке: трава, юрта, камни, брёвна, арена, забор | `assets/sprites/world/` |
| `togyz_art.py` | лунка, кольца, тұздық, камешек, қазан | `assets/sprites/togyz/` |
| `aq_suyek_art.py` | ночная клетка, следы, кольцо шага, сүйек, отау, фигурки | `assets/sprites/aq_suyek/` |
| `briefing_art.py` | 16 схем шагов для экранов-объяснений | `assets/sprites/briefing/` |
| `app_icon.py` | иконка приложения 512×512 | `assets/sprites/ui/app_icon.png` |
| `import_atilla.py` | перенос логотипа и фонов меню из atilla | `assets/sprites/ui/`, `backgrounds/` |

Схемы, картинки режимов и фигурки собираются из спрайтов других генераторов, поэтому
`build.py` вызывает генераторы по порядку зависимостей.

## Сетка и масштаб

- Рисуем в **пикселях арта** и сохраняем ×2 (`UiTokens.PIXEL`), без сглаживания.
- В игре картинки показываются только в целом масштабе. Окно масштабирует экран с шагом
  0,5 (`PixelScale`), поэтому пиксель арта на экране всегда целый: 2, 3 или 4 пикселя.
- Персонаж — клетка 32×32, иконки — 32×32, схемы объяснений — 96×48, мир — в
  пикселях мира того же размера.

## Палитра

`assets/palette/sanlaq.gpl` — 78 именованных цветов. Генераторы берут цвет только по
имени (`color("gold")`); смысловые цвета интерфейса (`GOLD`, `OUTLINE`) — из
`scripts/ui/ui_tokens.gd`, и все они обязаны быть в палитре.

## Проверка

`tools/style_test.gd` в CI проверяет каждый PNG в `assets/ui/frames`, `assets/ui/hud`
и `assets/sprites`:

- только цвета палитры (фоны меню из atilla тоже сведены к ней);
- альфа только 0 или 255;
- пиксельная сетка: размеры кратны пикселю арта, нет сглаживания и дробного масштаба.

Там же — контраст текста к рамкам темы (WCAG AA) и существование всех вариантов темы,
которые упоминаются в коде.
