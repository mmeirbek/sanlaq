# САҢЛАҚ / Sañlaq

Сборник казахских народных игр в пиксельном стиле: погоня «Соқыртеке» с викториной
об одежде, игра на память «Абай айтады», настольная «Тоғыз құмалақ» и ночная
игра-поиск «Ақ сүйек». Языки — казахский и английский.

**Движок:** Godot **4.7** (stable), GDScript. `main` после зелёных тестов
собирается в Web и выкладывается на GitHub Pages.

## Режимы

Из главного меню «ОЙНАУ» ведёт на выбор режима, оттуда — на **экран-объяснение**:
4 шага с пиксельными схемами и навыки, которым учит режим. Озвучка объяснений
включается переключателем и запоминается. При первом запуске поверх главного меню
показываются три карточки обучения.

### Соқыртеке — погоня (человек против ботов)

- Один игрок — **Соқыртеке** (ловец) с ограниченным обзором, остальные — бегуны.
  Роль выбирается в лобби, там же число ботов.
- Поймал бегуна — **квиз**: узнать вещь на пойманном по картинке, 10 секунд.
  Верно — бегун выбывает; неверно — ловец замедлен на 5 с, у бегуна щит на 2 с.
- Время раунда — 60 с + 15 с за каждого бегуна сверх первого. Поймал всех — победил
  ловец, иначе — бегуны.
- Вода замедляет, в юрте можно спрятаться. У ловца есть «үн тыңдау» (E), у бегуна —
  рывок (Shift).
- Одежда влияет на игру: тымақ сокращает замедление на 30%, шапан делает бегуна
  менее заметным, саптама етік ускоряет на суше. Вся одежда открыта сразу.

### Абай айтады — память (2–4 игрока на одном устройстве)

Абай показывает тізбек из карточек с блюдами, игроки по очереди повторяют. Каждый
раунд тізбек длиннее на одну карточку. Ошибившиеся вылетают вместе в конце раунда.

### Тоғыз құмалақ — настольная (вдвоём или против компьютера)

18 отау по 9 құмалақ, побеждает набравший 82. Реализованы все правила: взятие
чётной лунки, тұздық, атсырау. Бот — жадная эвристика на один ход.

### Ақ сүйек — поиск на ночном поле (против компьютера)

Ответ на вопрос о традициях даёт шаги, шаги тратятся на путь по полю 5×5.
Следы-подсказки показывают, горячо или холодно. Кто первым нашёл сүйек — берёт
раунд, партия — до двух побед.

## Запуск

1. Установите **Godot 4.7** (stable) — https://godotengine.org/download.
2. Откройте `project.godot` в редакторе, F5.

Управление:

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | WASD / стрелки | стик слева |
| Рывок бегуна / «үн тыңдау» ловца | Shift / E | кнопка справа |
| Ответ в квизе | 1–3 | касание |
| Назад, пауза | Esc | «Артқа», кнопка «II» в игре |
| Наблюдение после поимки | клик, Tab, Q, стрелки | кнопки ◀ ▶ |

## Как добавлять

- **Вещь одежды.** Слой персонажа и иконку нарисуйте в `tools/artgen/characters.py`
  и `item_icons.py`, пересоберите арт (`python tools/artgen/build.py`). Затем создайте
  `data/clothing/<id>.tres` по образцу соседних. Свойство в игре задаётся полями
  `slow_duration_mult`, `visibility_mult`, `dry_speed_mult` и подписью `effect_text`.
- **Слово для «Абай айтады».** `GameWord` в `data/words/`, иконку нарисуйте в
  `tools/artgen/food_icons.py`.
- **Вопрос для «Ақ сүйек».** `CultureQuestion` в `data/questions/` и строки в CSV.
- **Шаг объяснения режима.** Строку добавьте в `data/briefings/<режим>.tres` и в CSV,
  затем перегенерируйте озвучку (`python3 tools/generate_voice_lines.py`) и
  нарисуйте схему в `tools/artgen/briefing_art.py`.
- **Новый экран.** Корень — `Control`, сверху `ScreenHeader`, фон — `PixelBackdrop`.
  Кнопки — `PixelButton`, вид задаётся только `theme_type_variation`. Видимый текст
  проходит через `tr()`, ключ — казахская строка в `assets/i18n/ui_strings.csv`.
- **Новый режим.** Нужны:
  - сцена и скрипт в `scenes/ui/`, правила отдельным классом с тестами (как `GameBoard`);
  - `go_to_*()` в `SceneRouter` и карточка в `mode_select.tscn`;
  - `ModeBriefing` в `data/briefings/` и маршрут в `ROUTES` экрана объяснения;
  - пауза через `PauseMenu`;
  - проверки в `tools/modes_smoke_test.gd` и `tools/navigation_test.gd`.

## Тесты и проверки

```bash
tools/run_tests.sh                                  # все tools/*_test.gd, как в CI
godot --headless --path . --script res://tools/<имя>_test.gd
gdlint scenes scripts autoload tools                # линтер, настройки в gdlintrc
godot --path . --script tools/screenshot_screens.gd -- --size=1560x720   # скриншоты, НЕ headless
```

Каждый тест — гейт: при провале или при ошибке движка в логе он выходит с кодом 1.
Проверяются правила режимов, механика погони, экраны и их полный цикл, навигация
и пауза, переводы, покрытие шрифтов, палитра и пиксельная сетка арта, контраст
текста, масштаб пикселя. CI (`.github/workflows/ci.yml`) гоняет тесты и `gdlint`
на каждый PR, а из `main` собирает Web-версию.

## Сборка

Web-сборку делает CI. Вручную: Editor → Manage Export Templates (4.7) → Project →
Export → пресет Web, Windows, Linux, macOS или Android.

## Совместная работа

- Одна задача — одна ветка — один Pull Request. В `main` вливает команда.
- `.godot/` и `export/` не коммитятся; `*.uid` и `*.import` коммитятся — сцены
  ссылаются на ресурсы по UID.
- Пиксель-арт попадает в проект только через генераторы `tools/artgen/` или через
  импорт, прошедший `tools/style_test.gd`.
